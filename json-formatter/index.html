Frequently asked questions

        

          

            
What is a JSON formatter used for?

            
A JSON formatter re-indents machine-generated or minified JSON into a readable shape, which makes it far easier to inspect API responses, config files, and log payloads by eye.

          

          

            
Does this tool validate JSON as well as format it?

            
Yes. The input is parsed on every change, and any syntax error is reported with the position where parsing failed.

          

          

            
Is my JSON sent anywhere?

            
No. Parsing and formatting happen in your browser, so tokens, credentials, and personal data in a payload are never transmitted.

          

          

            
What is the difference between beautified and minified JSON?

            
Beautified JSON adds indentation and newlines for human readers. Minified JSON removes every optional whitespace character to reduce payload size; both parse to exactly the same data.

          

          

            
Does it support JSON with comments or trailing commas?

            
No. The validator follows the strict JSON specification, so comments and trailing commas are reported as errors.
