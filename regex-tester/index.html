About the Regex Tester

Write a JavaScript regular expression and see every match highlighted in your test text as you type. Capture groups are colour-coded and listed separately, so you can tell quickly whether a pattern grabs what you meant it to grab.

Features

  • •Live match highlighting over your own sample text.
  • •Colour-coded capture groups with a breakdown of each match.
  • •Toggle the g, i, m, and other flags.
  • •Built-in cheat sheet for the common tokens and quantifiers.
  • •Immediate feedback on invalid patterns.

How to use the Regex Tester

  1. 1Enter a pattern. Type your regular expression into the pattern field and set the flags you need.
  2. 2Paste test text. Add the sample text you want to match against.
  3. 3Inspect the matches. Matches are highlighted inline and capture groups are listed so you can verify each one.
  4. 4Refine. Adjust the pattern until only the intended text matches.

Frequently asked questions

Which regex dialect does this tester use?

It uses the JavaScript (ECMAScript) regular expression engine built into your browser, so behaviour matches what you get in Node.js and front-end code.

What do the g, i, and m flags do?

The g flag finds every match rather than just the first, i makes matching case-insensitive, and m makes ^ and $ match at line boundaries instead of only at the start and end of the whole string.

Why does my pattern match nothing?

The most common causes are an unescaped special character such as . ( ) [ ] or ?, a missing g flag when you expect several matches, and case sensitivity. Invalid patterns are reported as soon as you type them.

Are capture groups shown separately?

Yes. Each group is colour-coded in the highlighted text and listed per match so you can confirm what each one captured.

Is my test data private?

Yes. Patterns and sample text are evaluated in your browser and never sent anywhere.

Privacy

Everything on this page runs in your own browser. Your input is never uploaded, never stored on a server, and never logged. The tool is free, open source, and needs no account.
