About the UUID Generator

A UUID is a 128-bit identifier written as 36 characters, used as a primary key or correlation id when values must be unique without a central authority. This generator produces version 4 (random) UUIDs using the browser’s cryptographic random number generator.

Features

  • •Cryptographically secure UUID v4 generation via the Web Crypto API.
  • •Generate a single identifier or a large batch with one slider.
  • •Copy an individual UUID or the whole list at once.

Frequently asked questions

What is a UUID v4?

Version 4 UUIDs are generated from random data, with 122 random bits plus fixed version and variant bits. They need no coordination between systems, which makes them ideal for distributed ids.

Are these UUIDs really unique?

In practice, yes. With 122 random bits, the chance of a collision is negligible — you would need to generate billions of UUIDs before a duplicate became even remotely likely.

Are the UUIDs cryptographically secure?

Yes. They are produced from the browser’s Web Crypto random number generator rather than Math.random, so the values are not predictable.

What is the difference between a UUID and a GUID?

They are the same 128-bit identifier format. GUID is Microsoft’s name for it, and the two terms are used interchangeably.

Should I use a UUID as a database primary key?

It works well for distributed systems and for ids exposed publicly. Be aware that random UUIDs scatter inserts across an index, so on very large tables a time-ordered id scheme can perform better.
