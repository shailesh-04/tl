About the Developer Tools Dashboard

Every tool in the library, searchable in one place. All of them run entirely in your browser — nothing is uploaded, nothing is stored on a server, and none of them need an account.

Features

  • •Search and filter across the whole tool collection.
  • •Converters for JSON, CSV, XLSX, XML, and TSV.
  • •Encoding, regex, and identifier utilities for everyday development.
  • •Media tools for compressing images and converting video.
  • •Free, open source, and fully client-side.

Frequently asked questions

Are these tools really free?

Yes. Every tool is free and open source, with no account, no usage cap, and no paid tier.

Do the tools work offline?

Once a tool page has loaded, the processing itself runs locally. The page does fetch its fonts and styling from CDNs on first load, so the initial visit needs a connection.

Is my data private?

Yes. Every tool processes your input in your own browser, so files and text are never uploaded to a server.

Privacy
