About the Base64 Encoder & Decoder

Base64 encodes arbitrary bytes using 64 printable ASCII characters so that binary data can travel safely through text-only channels such as JSON payloads, data URIs, email bodies, and HTTP headers. This tool converts in both directions with correct UTF-8 handling for accents, emoji, and non-Latin scripts.

Features

  • •Encode plain text to Base64 and decode Base64 back to text.
  • •Correct UTF-8 handling, so emoji and non-Latin alphabets round-trip cleanly.
  • •Switch direction with a single toggle; output updates as you type.
  • •One-click copy of the result.

Frequently asked questions

Is Base64 encryption?

No. Base64 is an encoding, not encryption. Anyone can decode it, so it must never be used to protect passwords, tokens, or other secrets.

Why does Base64 output look longer than the input?

Base64 represents every three bytes as four characters, so encoded data is roughly 33% larger than the original.

Does this tool support UTF-8 and emoji?

Yes. Text is converted to UTF-8 bytes before encoding and decoded back the same way, so accented characters, emoji, and non-Latin scripts survive the round trip.

What are the trailing "=" characters?

They are padding. Base64 works in blocks of three input bytes, and "=" pads the final block when the input length is not a multiple of three.

Is my data sent to a server?

No. Encoding and decoding happen in your browser, so nothing you paste is uploaded or logged.

Privacy
