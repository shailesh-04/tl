About the Image Optimizer & Compressor

Large images are usually the single biggest drag on page weight and Core Web Vitals. This optimizer re-encodes pictures locally using the browser’s canvas pipeline, letting you trade a little quality for a large drop in file size and see the result side by side before you download anything.

Features

  • •Compress JPEG, PNG, and WebP images with an adjustable quality slider.
  • •Convert between formats — WebP typically saves the most bytes.
  • •Resize by width or height while keeping the aspect ratio.
  • •Before/after comparison slider plus the exact size saving in bytes.
  • •Processing happens on your device, so private photos are never uploaded.

How to use the Image Optimizer & Compressor

  1. 1Add an image. Drag a JPG, PNG, or WebP file onto the drop area, or click to browse.
  2. 2Choose format and quality. Pick the output format and move the quality slider until the size and sharpness suit you.
  3. 3Resize if needed. Optionally set a target width or height; the aspect ratio is preserved.
  4. 4Compare and download. Drag the before/after handle to inspect the result, then download the optimized file.

Frequently asked questions

Which format should I choose for the web?

WebP is the best default for photographs and most graphics — it is widely supported and usually 25–35% smaller than an equivalent JPEG. Keep PNG only when you need lossless output or sharp-edged graphics with transparency.

What quality setting should I use?

For photographs, 75–85 is a good balance: the file is far smaller and the difference is hard to see. Drop lower only for thumbnails, and go higher for images with fine text or detail.

Does compressing lose quality?

JPEG and WebP compression is lossy, so some detail is discarded. The comparison slider lets you judge it directly before downloading, and your original file is never modified.

Are my images uploaded to a server?

No. Images are decoded and re-encoded entirely in your browser, so personal photos and unreleased assets never leave your device.

Does optimizing images help SEO?

Yes, indirectly. Smaller images improve Largest Contentful Paint and overall page speed, which are part of Google’s page experience signals and reduce bounce on slow connections.
